# 과거 증거의 익명화 파생본

v2 인수의 익명화 요구에 따라 기존 문서 2개와 압축 로그 7개의 개인 Windows 홈 경로를 `C:/Users/mock-user` 또는 같은 의미의 역슬래시 표기로 치환했다. 원본과 파생본의 SHA-256, 파일별 치환 범주는 [redaction-provenance.json](redaction-provenance.json)에 기록한다. 실제 치환 대상 값은 기록하지 않고 비공개 로컬 denylist를 사용했다.

기존 Git 이력은 다시 쓰지 않았다. 현재 추적되는 로그는 **익명화 파생본**이며 원문 바이트와 같다는 주장을 철회한다. 명령 구조, 실행 결과, 실패 시도, 수치와 종료코드는 보존했다. 기존 v1 bundle manifest와 체크섬은 당시 원본 산출물의 역사적 식별 기록이며, 현재 익명화된 문서/로그의 체크섬으로 재사용하면 안 된다. 원본을 다시 공유하면 개인 경로가 노출될 수 있으므로 v2 반입 패키지에서는 과거 증거 전체를 명시적으로 제외한다.

문서에는 이 안내를 추가했으므로 해당 문서의 파생본 hash는 경로 치환과 안내 추가를 모두 반영한다. gzip 로그는 디코딩한 본문에서 경로만 치환했으며 다시 압축했다. 공개 제3자 라이선스·저작권 고지는 수정하지 않았다.
